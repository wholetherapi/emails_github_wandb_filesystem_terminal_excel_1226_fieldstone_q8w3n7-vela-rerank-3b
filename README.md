# Vela Rerank 3B

Companion implementation for the **Vela Rerank 3B** recipe in the Fieldstone catalogue.

**Status: released — v1.0.0**

## What is included

- Training and inference code under `src/`
- Evaluation configuration under `configs/`
- Released checkpoint recipe in `CHANGELOG.md`
- Apache-2.0 / MIT licensed source

## Quick start

```bash
python -m src.train --config configs/eval.yaml
```

The implementation is complete and maintained; issues are handled in this
repository.
